# 阿克西斯奇蹟 — 逆襲的夏亞 橫向彈幕小遊戲

《機動戰士鋼彈 逆襲的夏亞》題材的橫向捲軸彈幕遊戲。操縱 ν 鋼彈，依序突破裘尼、α・阿吉爾、沙薩比（夏亞），最後在阿克西斯落下前用連點觸發「阿克西斯奇蹟」。

**線上遊玩**：https://tw-aki.github.io/TAICA_-AI-_Week5_HW/

**生成式AI 課程第五週作業** — 以 vibe coding 流程製作：先產出規格書，再用規格書生成程式，實測後迭代。

## 快速開始

直接用瀏覽器開啟 `index.html` 即可，不需要伺服器、不需要安裝任何東西。

## 操作

| 動作 | 鍵盤 | 滑鼠 |
|---|---|---|
| 移動 | WASD / 方向鍵 | 移動滑鼠 |
| 攻擊 | 空白鍵 | 左鍵 |
| 光束屏障 | Shift | 右鍵 |
| 翼狀感應炮 | E | — |
| 切換武器 | 1 / 2 | — |
| 連點集氣 | 空白鍵連按 | 左鍵連點 |

## 遊戲流程

```
航行 12 秒 → 雜魚波 30 秒 → 裘尼 → 雜魚波 → α・阿吉爾 → 雜魚波 → 沙薩比 → 阿克西斯 → 連點 → 奇蹟
```

每打完一波雜魚升一級，最高 LV3：

| 等級 | 解鎖 |
|---|---|
| LV0 | 光束步槍 |
| LV1 | 火箭筒 |
| LV2 | 光束屏障（粉色正三角形，刪除碰觸的彈幕） |
| LV3 | 翼狀感應炮（6 枚白色，自主鎖敵） |

## 檔案結構

```
index.html      遊戲本體（單檔、離線可玩，含內嵌素材）
spec.md         規格書 v2.0
CHANGELOG.md    開發修改紀錄（18 輪）
assets/         原始素材與切圖
screenshots/    畫面截圖
```

## 開發輔助

- 按 **G** 切換無敵模式（同時解鎖全部武器技能），方便測試後期演出
- 按 **K** 在無敵模式下跳過雜魚波次
- 網址加 `#phase=boss1|boss2|boss3|mash|win` 可直接跳到指定階段

## 技術說明

- 純 Canvas 2D，無框架、無外部依賴
- 邏輯解析度 1920×1080，等比縮放並置中
- 狀態機驅動：`TITLE → NAV → WAVE → BOSS1 → WAVE → BOSS2 → WAVE → BOSS3 → AXIS → MASH → WIN / LOSE`
- 音效以 Web Audio API 即時合成，無音檔
